# 字幕勘误台

同一句采访可能被剪进几版纪录片。源字幕更正后，本工具按等速换算把更正前后与
各剪辑段的重叠部分折算成**成片时码**，出具勘误单，逐段列出要**删除 / 补加 /
替换**的字幕及新旧时码，供档案员逐版核对修改。

## 启动

```bash
docker compose up --build
# 打开 http://localhost:8000
```

数据保存在名为 `errata-data` 的卷中（容器内 `/data/errata.db`）。

本地开发（无需 Docker）：

```bash
pip install -r requirements.txt
python app.py            # 监听 8000 端口
python -m pytest tests/  # 运行自测
```

## 使用流程

1. **上传素材字幕 CSV**，列：`素材号,句号,开始毫秒,结束毫秒,原文`
   （兼容 UTF-8 BOM；同一句重复上传会覆盖，内容有变化时版本号归零）。
2. **上传等速剪辑表 CSV**，列：`成片号,剪辑段号,素材号,截取开始毫秒,截取结束毫秒,成片起点毫秒`。
3. 在“素材字幕”页选一句点**修订**，按所见改正文字或起止毫秒，提交。
4. 系统出具勘误单：原句更正与勘误单在**同一事务**中生效；
   后续更正出具新单，**不改变已出单据**；单据可按素材号 / 句号 / 成片号查询。

## 换算规则

- 所有区间为**左闭右开** `[开始, 结束)`；端点刚好相接不算重叠。
- 等速剪辑为 1:1 平移：`成片时码 = 成片起点 + (素材时间 − 截取起点)`。
- 对引用该素材的每个剪辑段，分别计算更正前、后句子区间与段截取区间的重叠：
  - 仅更正前有重叠 → **删除**（给出旧时码）；
  - 仅更正后有重叠 → **补加**（给出新时码）；
  - 两者都有重叠 → **替换**（同时给出新旧时码与新旧原文）；
  - 换算后时码相同且文字未变 → 该段无可见变化，不列条目。

## 出单规则

- 提交时携带所见的**版本号**：若该句已被他人更新（修订过期），不出单、原句不变。
- 输入非法（起止颠倒、原文为空、未做任何修改）或句目不存在：不出单、原句不变。
- 出单与更新原句为原子操作：任一步失败整体回滚。
- 勘误单出具后不可更改、不可删除，永久可查。

## CSV 表头别名

中文标准列名之外也接受英文别名，如 `material_id/sentence_id/start_ms/end_ms/text`
与 `program_id/segment_id/cut_start_ms/cut_end_ms/program_start_ms`。
样例文件见 `sample_data/`。

## 目录结构

```
app.py         Flask 路由与出单事务
core.py        区间重叠、等速时码换算、勘误条目生成
csv_import.py  CSV 解析与逐行校验（出错整文件不入库）
db.py          SQLite 连接与建表
templates/     页面模板
tests/         pytest 自测（换算、出单、过期、不可变等）
sample_data/   演示用 CSV
```
